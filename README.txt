QWITTY — ОФИЦИАЛЬНЫЙ САЙТ (v3)

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Открой репозиторий qwittydev.github.io.
2. Загрузи содержимое архива В КОРЕНЬ репозитория: index.html, style.css, script.js, .nojekyll, robots.txt, sitemap.xml и assets/.
3. Заменяй старые файлы новыми. НЕ удаляй HTML-файл подтверждения Google Search Console.
4. Добавь QwittyGram.apk в корень рядом с index.html — кнопки «Скачать» заработают автоматически.
5. Ограничение веб-загрузки GitHub: 25 МиБ на файл. Для большого APK используй git / GitHub Desktop. У GitHub есть лимиты репозитория и Pages; файл APK ~65 МБ находится в пределах 100 МиБ обычного git-файла, но это не лучший вариант при большом трафике.
6. Ссылка на Qwitty Bot: https://t.me/Qwitty_bot
7. Техническая поддержка только внизу сайта: https://t.me/QwittySupport
8. Внешних переходов на GitHub внутри сайта нет. Сам адрес qwittydev.github.io будет виден в адресной строке, пока не подключишь собственный домен.
9. Сайт не требует Node.js или backend. При переносе на свой домен поправь canonical, og:url, og:image, sitemap.xml и robots.txt.

СОДЕРЖИМОЕ
- assets/qwittygram.webp — основной логотип Qwitty и QwittyGram
- assets/qwittybot.webp — логотип кота для Qwitty Bot
- assets/favicon.png — favicon
- assets/og-cover.jpg — изображение для превью в соцсетях

APK не вложен в ZIP. Добавь свою актуальную сборку с именем QwittyGram.apk самостоятельно.
